# 📚 Story Reader — Kids Reading PWA

A free, installable reading app for children. Reads books aloud, highlights every word, and lets kids tap words to see definitions.

**Supports:** PDF · EPUB · MOBI · AZW / AZW3 · TXT

---

## 🚀 How to Deploy (Free — takes ~5 minutes)

### Step 1 — Create a GitHub account
Go to **github.com** and sign up for a free account if you don't have one.

### Step 2 — Create a new repository
1. Click the **＋** button (top right) → **New repository**
2. Name it exactly: `story-reader`
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload the files
1. On your new repository page, click **"uploading an existing file"**
2. Drag and drop ALL these files/folders:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/` folder (with both PNG files inside)
3. Scroll down and click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Click **Settings** tab (in your repository)
2. Click **Pages** in the left sidebar
3. Under "Source", select **main** branch, folder **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes, then your app is live at:
   **`https://YOUR-USERNAME.github.io/story-reader`**

---

## 📱 Install on iPhone / iPad

1. Open Safari and go to your GitHub Pages URL above
2. Tap the **Share button** (box with arrow at bottom)
3. Tap **"Add to Home Screen"**
4. Tap **Add**

The app icon appears on your home screen and opens full-screen like a real app!

## 📱 Install on Android

1. Open Chrome and go to your GitHub Pages URL
2. Tap the **three dots menu** (top right)
3. Tap **"Add to Home screen"** or **"Install app"**
4. Tap **Add**

## ✨ Features

- 📖 Reads aloud with word-by-word highlighting
- 👆 Tap any word to see its definition + phonics breakdown
- 📚 Library remembers all your books
- 🌙 Night mode for bedtime reading  
- 🐌 Four speeds including Very Slow
- 🎙 Voice picker — choose the most natural voice on your device
- ⭐ Word counter rewards for kids
- Works offline once installed

---

## 💡 Tips

- **Best voices on iPhone/iPad:** Go to Settings → Accessibility → Spoken Content → Voices → English, then download "Samantha (Enhanced)" — it sounds very natural
- **Kindle books:** Amazon's DRM-protected books need to be converted first using the free **Calibre** app on a computer, then exported as EPUB
- **Scanned PDFs** (photographs of pages) won't work — the PDF needs actual selectable text
